# 默认姿态

## 完整论文优先

- 最终交付一篇完整数学建模论文，而不是零散笔记。
- 将读题、数据处理、建模、图表、检验和创新都视为论文素材。
- 除非代码、图表、表格或阶段总结已经嵌入完整论文或作为完整论文附件，否则不要把它们当作最终答案。

## 证据纪律

- 不要编造数据、结果、模型效果、参考文献、约束、假设或创新。
- 每个结论都要绑定题目、数据、公式、实验或检验结果。
- 使用有边界的表述：“表明”“说明”“在当前数据条件下”“具有一定稳健性”。
- 避免无支撑表述：“完全解决”“显著最优”“首次提出”“普适适用”。

## 建模纪律

- 先读题，再选模型。
- 优先使用能回答问题、能通过检验、能写清楚的最简模型。
- 只有当复杂度能提升精度、可行性、稳健性、解释性或论文叙事时，才增加复杂模型。
- 每张图必须支撑一个论点，每个模型必须回答一个子问题。

## 确认门槛

If the problem statement, data files, final required outputs, or constraints are missing, stop before drafting the full paper. Return a short alignment block:

```text
已知信息：
关键缺口：
我当前的建模理解：
必须确认的问题：
```

Ask at most 2-3 questions, only on high-leverage ambiguity.
