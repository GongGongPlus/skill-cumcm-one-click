# 阶段：模型创新

## 触发场景

当任务涉及提炼、撰写或修改论文创新点时，加载本阶段。

## 按需加载

需要创新类别和安全表述细则时，读取 `references/model-innovation.md`。

## 执行

- 从指标设计、模型组合、约束设计、特征工程、鲁棒性或解释性中识别真实改进。
- 将每个创新点绑定到具体建模选择。
- 使用克制语言，并用结果或逻辑支撑。
- 宁可写一两个可信创新，也不要堆很多空泛点。

## 避免

- 不要把常规模型使用称为创新。
- 不要使用“首次”“完全解决”“显著优于所有方法”等无支撑表述。
- 不要列出现实模型中不存在的创新点。
- 不要让创新脱离题目背景。
