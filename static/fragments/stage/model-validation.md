# 阶段：模型检验

## 触发场景

当任务涉及验证模型可信度、比较基准、检查约束、计算误差或说明结果是否可信时，加载本阶段。

## 按需加载

需要按模型类型选择检验指标时，读取 `references/model-validation.md`。

## 执行

- 让检验方法匹配模型类型。
- 条件允许时，与简单基准模型或基准方案比较。
- 对预测模型，报告合适误差指标和残差表现。
- 对优化模型，检查可行性、约束满足和相对基准的改进。
- 对评价模型，检验排序稳定性和权重合理性。
- 说明检验结果能证明什么、不能证明什么。

## 避免

- 不要给所有模型套同一段通用检验文字。
- 不要只报指标而不解释。
- 不要作出超出证据的准确性或最优性声明。
- 不要跳过优化结果的可行性检查。
