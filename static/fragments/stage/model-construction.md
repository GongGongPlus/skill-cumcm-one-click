# 阶段：模型建立

## 触发场景

当任务涉及选择模型、定义变量、书写目标函数、设置约束、设计算法或解释求解路线时，加载本阶段。

## 按需加载

需要模型族和写作细则时，读取 `references/model-construction.md`。

## 执行

- 将每个子问题映射到一条模型路线。
- 说明所选模型为什么匹配任务、数据、约束和输出要求。
- 定义变量、参数、目标函数或评价函数、约束和求解步骤。
- 详细展开模型底层原理：从输入数据如何进入变量、变量如何进入公式、目标函数如何被优化、算法如何迭代或求解、输出如何转化为题目答案。
- 对每个关键公式逐项解释符号、量纲、参数来源、约束含义和它在求解流程中的作用。
- 对机器学习、统计预测、评价或优化算法，写清训练/求解流程、参数选择、停止条件、评价指标和结果边界，不能只写模型名称。
- 除非有证据证明复杂模型必要，否则优先选择可解释、可检验模型。
- 当一个模型结果进入另一个模型时，明确输入输出衔接，例如先预测再优化。

## 避免

- 不要堆叠无关模型来显得复杂。
- 不要写公式却不解释符号。
- 不要使用没有检验和解释的黑箱方法。
- 不要用一两句话带过模型原理、训练过程或求解步骤。
- 不要建立无法产出题目所需结果的模型。
