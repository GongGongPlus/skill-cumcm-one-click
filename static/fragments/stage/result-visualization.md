# 阶段：结果可视化

## 触发场景

当任务涉及将模型输出转化为论文中的图、表、排名、地图、曲线或结果解释时，加载本阶段。

## 按需加载

需要图表选择和结果解释细则时，读取 `references/result-visualization.md`。

## 执行

- 按图表在论证中的作用选择图表。
- 用表格呈现精确数值，用图形呈现模式、比较和趋势。
- 主动规划图表类型组合，至少覆盖趋势/分布/比较/关系/误差或贡献中的多种类型，避免整篇论文只有柱状图或折线图。
- 生成图时必须使用 Python 绘图库，优先 matplotlib、seaborn、plotly、networkx 或 statsmodels；不要用 AI 生成图片、截图、PPT 形状或手工拼贴图替代数据图。
- 图中文字必须统一字体：中文宋体，英文和数字 Times New Roman。保存高分辨率 PNG/PDF/SVG 时显式设置字体、字号、线宽和输出 dpi。
- 生成图时使用统一、克制且美观的配色和版式，不使用默认低质样式、彩虹色、低对比度、拥挤标签、发光卡片、渐变堆叠或明显 AI 海报感。
- 每个子问题至少设计一个有创新表达的图，例如“总览+细节”复合图、校准曲线、误差云图、系数森林图、分组轨迹图、相关性聚类热力图、事件时间图或敏感性响应面；创新必须服务论证，不做装饰。
- 每张图出现后立即解释。
- 每张图后必须有针对性解释，说明图中的关键现象、支撑的题目结论和建模含义。
- 按原题问题编号组织结果，不按脚本运行顺序组织。
- 使用一致的图注、单位、标签和术语。

## 避免

- 不要加入装饰性图表。
- 不要交付非 Python 生成的论文图表。
- 不要让图表孤立出现而无解释。
- 不要使用单一图型重复堆叠，也不要让整篇论文呈现单调配色。
- 不要交付模糊、拉伸、文字过小、标签遮挡、图例压住数据或颜色难以区分的图。
- 不要用原始输出填满论文。
- 不要展示与原题问题无连接的结果。
