# 高频模型速查（CUMCM A/B/C + MCM A-F）

## 题型判定与候选模型

| 题型 | 典型特征 | 高频模型 |
| --- | --- | --- |
| 评价/决策类 | 给多个方案/对象排序、打分 | 层次分析 AHP、熵权法、TOPSIS、模糊综合评价、灰色关联 |
| 预测类 | 给历史数据预测未来 | 线性/多元回归、时间序列（ARIMA/指数平滑）、灰色 GM(1,1)、Prophet、机器学习回归 |
| 优化类 | 求最大/最小、资源配置、路径 | 线性/整数/非线性规划、动态规划、遗传算法、模拟退火、蚁群 |
| 统计/数据分析类 | 找规律、显著性、分类 | 假设检验、方差分析、聚类（K-means）、主成分分析、相关分析 |
| 图论/网络类 | 路径、网络、调度 | 最短路（Dijkstra/Floyd）、最小生成树、最大流、指派/匹配 |
| 机理/物理类 | 有物理规律、动态过程 | 常/偏微分方程、差分方程、元胞自动机、排队论 |
| 机器学习类 | 大数据分类/预测 | 逻辑回归、随机森林、XGBoost、神经网络（适度使用） |
| 博弈/分配类 | 多方利益、策略 | 纳什均衡、合作博弈、多目标规划 |
| 多目标 | 多个冲突目标 | 加权法、ε-约束、NSGA-II（pymoo） |

## 选模原则

- 基线优先：先用成熟简单模型出结果（如线性回归/线性规划），再叠加一处改进。
- 数据决定模型：小样本→统计/灰色；中样本→传统机器学习；时间序列→先做平稳性检验。
- 每个模型要能解释：为什么选它、假设是什么、局限在哪。
- 允许主模型 + 对比模型，对比模型用于检验主模型。

## 常用库

- Python：scipy.optimize、pulp（规划）、networkx（图论）、statsmodels（统计/时间序列）、scikit-learn（机器学习）、pymoo（多目标）、DEAP（遗传算法）、matplotlib（绘图）。
- MATLAB：Optimization Toolbox（fmincon/intlinprog）、Statistics Toolbox、plot 系列。

## 万能兜底流程

数据 → 描述性统计 → 相关/聚类探规律 → 基线模型 → 一处改进 → 检验 → 灵敏度 → 结论
