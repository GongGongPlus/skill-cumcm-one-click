# 阶段：数据预处理与可视化

## 触发场景

当任务涉及检查数据、清洗数据、构造特征、指标标准化或绘制探索性图表时，加载本阶段。

## 按需加载

需要缺失值、异常值、特征工程和可视化细则时，读取 `references/data-preprocessing-visualization.md`。

## 执行

- 建立数据台账：文件、字段、含义、单位、范围、缺失、异常和支撑的子问题。
- 只有在理由明确时才清洗或删除数据。
- 保留可能影响模型的信息，不要盲目删除记录。
- 合并数据前统一时间、空间、单位、类别和统计口径。
- 构造与题目背景相关、可解释的特征。
- 用探索性图表支撑模型选择和变量处理。

## 避免

- 不要把每个清洗步骤都当作最终输出。
- 不要绘制不支撑建模决策或论文结论的图。
- 不要在未判断正向、负向、适度指标前直接标准化。
- 不要在终稿中隐藏关键预处理选择。
