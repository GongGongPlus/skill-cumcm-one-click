# 阶段：敏感性分析

## 触发场景

当任务涉及检验结论是否依赖权重、参数、阈值、约束、初始条件或情景假设时，加载本阶段。

## 按需加载

需要扰动分析和稳健性写法细则时，读取 `references/model-validation.md`（敏感性分析已并入该文件末尾）。

## 执行

- 只选择高影响参数或假设。
- 解释每个被检验因素为什么重要。
- 根据数据、题目背景或合理竞赛惯例设置扰动范围。
- 报告核心结论是否改变。
- 将敏感性结果转化为可靠性或决策含义。

## 避免

- 不要扰动无关变量。
- 不要设置无解释的任意范围。
- 如果结果发生实质变化，不要声称模型稳健。
- 不要让敏感性分析脱离论文结论。
