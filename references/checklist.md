# 交付前评审清单（评委视角，百分制）

## 一、内容完整性（40 分）

- [ ] 所有小问都有建模 + 求解 + 数值结果 + 结论
- [ ] 每问输出与题目要求一一对应（数值、单位、格式）
- [ ] 模型假设合理且与题意不矛盾
- [ ] 模型检验有实际内容（残差/对比/交叉验证）
- [ ] 灵敏度分析完成并有结论
- [ ] 模型优缺点、适用范围、推广有实质内容

## 二、摘要质量（20 分）

- [ ] 200–300 字
- [ ] 四问齐全：问题/模型/数值结果/结论意义
- [ ] 无"效果较好"类空话，有具体数字
- [ ] 无表格、图表、公式
- [ ] 无主观感受与修饰词

## 三、格式与规范（20 分）

- [ ] 题目简明准确
- [ ] 结构顺序符合要求（12 部分）
- [ ] 论文第 1 页为摘要页（含关键词），单独占 1 页；页码下居中
- [ ] 结构以问题为主线，每问开始呼应题目、结束有总结
- [ ] 符号表完整、符号一致
- [ ] 正文小四宋体、单倍行距、首行缩进；标题加粗
- [ ] 公式用公式编辑器，新罗马斜体，无 * 乘号、无编程公式
- [ ] 正文所有变量首次出现有解释；公式编号
- [ ] 参考文献规范、正文有 [n] 标注
- [ ] 页数、字体、命名符合当届规则
- [ ] 匿名：无学校/姓名/学号/联系方式
- [ ] 参考文献前有"AI 工具使用声明"，措辞与当届规定一致
- [ ] 支撑材料清单包含"AI工具使用详情.pdf"；使用 AI 的附同名 PDF 文件
- [ ] 附录居中另起一页，至少含支撑材料清单和程序代码
- [ ] 附录标题明确写"支撑材料清单"；不分个人分工
- [ ] 正文不超过 30 页；论文与支撑材料均不超过 20M
- [ ] 正文无目录；页码从摘要页（第 1 页）开始、下居中
- [ ] 支撑材料不含题目和附件（除非题目要求）
- [ ] 邮件/文件名规范：题号+组号_姓名1_姓名2_姓名3；不出现学校姓名

## 四、图表质量（10 分）

- [ ] 每图有坐标轴 + 单位 + 图题 + 图注
- [ ] 图与结果数据一致，无截断/夸大刻度
- [ ] 问题分析配流程图
- [ ] 300 DPI 清晰度，统一风格

## 五、可复现与诚信（10 分）

- [ ] 代码可运行，固定随机种子
- [ ] 关键数字能溯源到 results/ 文件
- [ ] 数据清洗过程有记录
- [ ] 无伪造数据/结果
- [ ] 提供复现说明（环境 + 命令）

## 自评输出

得分 /100；扣分点列表；预估位次区间；优先修改建议（按扣分权重排序）。

## 独立验收铁律（全网对标补强）

建模终检/最小可运行/编程终检/论文终检 MUST 由未参与该产物编写的独立检查执行并以证据返回；主流程自检不得描述为"独立通过"；环境不支持时只能报 BLOCKED。

## 五门禁强制序列（全网深挖，来源 XiaoMaColtAI/math-modeling-skill）

M1 建模终检 → P1 最小可运行结果 → P2 编程终检 → W1 证据大纲 → W2 论文终检。**P1 通过后才能全量计算与正式出图；W1 通过后才写长篇正文与双格式排版；禁止等全流程结束才首次质检**。FAIL 必须按证据返回修正并复验；产物实质变化 → 相关 PASS 立即失效。

- 文献检索硬上限：最多 5 次 WebSearch、找到 5-8 篇即停；中英文各 2-3 次。
- 代码附录（不满足可能取消评奖资格）：必须可完整运行、按子问题分节注释、**变量名与论文符号一致**、**代码输出与论文数据一致（建议 assert 验证）**、Python 注明依赖版本、不附调试打印与旧代码。
- 篇幅参数：国赛摘要 500-800 字；灵敏度 1-3 页；参考文献 ≥5；美赛 O 奖基准 Our Work 流程图近乎必须、AI Report 约 37% 需声明。
